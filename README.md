# Level 2 Search Prototype

Run locally with VS Code Live Server:

1. Copy this folder into `dev/level2-search/`.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**.

No `clasp push` is needed.

The pure engine is in `search-engine.js`. It has no DOM, Apps Script, or `google.script.run` dependency.

Open `tests.html` with Live Server to run the basic browser tests.
